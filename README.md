# QR-Find — локальный сайт для поиска и возврата вещей

## Важно: как правильно открыть сайт
Не открывайте `static/index.html` двойным щелчком. Тогда браузер покажет только внешний вид, а регистрация, вход, сохранение вещей и QR-коды работать не будут. Сайт нужно запускать через локальный сервер.

## Запуск в Windows
1. Установите Python 3.10 или новее. При установке с python.org отметьте **Add Python to PATH**.
2. Распакуйте архив целиком в отдельную папку.
3. Откройте папку `qr_find`.
4. Дважды нажмите `start_windows.bat`. При первом запуске программа создаст виртуальное окружение и установит библиотеки. Нужен интернет только для первой установки.
5. Когда появится сообщение о запуске, откройте **http://127.0.0.1:8000**. Чёрное окно консоли оставьте открытым, пока пользуетесь сайтом.

## Регистрация и работа
- Нажмите **Регистрация** или **Создать аккаунт**.
- Введите имя, электронную почту и пароль от 8 символов.
- После регистрации откроется личный кабинет.
- Добавьте вещь, скачайте её QR-код и распечатайте.
- При сканировании QR-кода откроется публичная карточка вещи, где нашедший сможет отправить сообщение.
- Сообщения будут доступны владельцу в личном кабинете.

## Локальная база данных
Используется SQLite. Файл `qrfind.db` автоматически создаётся в папке проекта рядом с `app.py` при первом запуске сервера. В нём хранятся аккаунты, вещи и сообщения. Данные остаются на этом компьютере и не отправляются во внешнюю облачную базу. Не удаляйте этот файл, если хотите сохранить данные. Для резервной копии остановите сервер и скопируйте `qrfind.db` в безопасное место. Загруженные фотографии лежат в папке `uploads`.

## Запуск вручную (если BAT не запускается)
Откройте терминал в папке `qr_find` и выполните по очереди:

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m uvicorn app:app --host 127.0.0.1 --port 8000
```

Затем откройте http://127.0.0.1:8000. Остановка — `Ctrl+C`.

## Состав функций
- регистрация и вход;
- личный кабинет пользователя;
- добавление вещей с описанием и фотографией;
- уникальный QR-код для каждой вещи;
- публичная страница вещи по QR-ссылке;
- отправка сообщения нашедшим без публикации личных контактов владельца;
- просмотр сообщений владельцем;
- статусы «Ищем», «Найдена», «Возвращена»;
- локальная база SQLite.

Это локальная учебная версия. Для размещения в интернете потребуются HTTPS, отдельный секрет сессии, резервное копирование, ограничение частоты запросов и дополнительная проверка загружаемых файлов.
